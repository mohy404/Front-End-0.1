ما هو Web Development؟

Web Development يعني «تطوير المواقع»: بناء أي صفحة أو تطبيق بتفتحه من المتصفح، زي موقع مدرستك أو يوتيوب أو متجر أونلاين.

أي موقع بتدخله فيه جزئين شغالين مع بعض: جزء بتشوفه وجزء مستخبي ورا الكواليس. وده بيوديني للقسم الجاي.

💡 فكّر كدهالموقع زي مطعم: فيه صالة بيقعد فيها الزبون، وفيه مطبخ بيتحضّر فيه الأكل.

Front-End – الواجهة اللي بتشوفها

الـFront-End هو كل حاجة بتظهر قدامك في المتصفح وتتعامل معاها: الألوان، الأزرار، الصور، الكتابة، والقوائم. هو «صالة المطعم».

مطور الـFront-End مسؤول إن الواجهة تبقى حلوة وسهلة وتشتغل على الموبايل والكمبيوتر.

Back-End – الكواليس

الـBack-End هو الجزء اللي شغال على سيرفر (جهاز قوي متوصل بالإنترنت)، وانت مش بتشوفه. هو «مطبخ المطعم».

وظيفته: يحفظ البيانات في قاعدة بيانات، ويتأكد إن الباسورد صح، ويجيب الرسايل والمنتجات ويبعتها للواجهة.

⚠️ لاحظالدرس ده Front-End بس. فأي زرار هنعمله هنا مش هيحفظ بيانات حقيقية، لأننا لسه ما اتعلمناش Back-End.

API – الجرسون بين الزبون والمطبخ 🧑‍🍳

الزبون (Front-End) مش بيدخل المطبخ (Back-End) بنفسه. فيه API بيشتغل جرسون: ياخد الطلب للمطبخ ويرجّع الرد.

  1. الزبون بيطلب (مثلاً: «هات منتجاتي»).
  2. الـAPI بيوصّل الطلب للـBack-End.
  3. الـBack-End بيجهّز البيانات.
  4. الـAPI بيرجّعها للواجهة وتتعرض قدامك.

ما هي لغة البرمجة؟

أي لغة هدفها إننا نكلّم الكمبيوتر. بس مش كل اللغات بتعمل نفس الشغلانة:

اللغةنوعهابتعمل إيه

⚠️ خطأ شائعHTML مش لغة برمجة. هي بتوصف المحتوى بس ومفيهاش منطق. اللغة البرمجية الوحيدة من التلاتة هي JavaScript.

مقدمة عن HTML

HTML اختصار HyperText Markup Language. يعني لغة بنكتب بيها علامات (Tags) بتقول للمتصفح: «ده عنوان، وده فقرة، وده زرار».

المتصفح بيقرأ الملف ويعرض النتيجة. جرّب بنفسك في الـPlayground اللي تحت.

🧪 Playground: عدّل الكود وشوف النتيجة

💡 جرّبغيّر الكلام جوه التاج واضغط Run، النتيجة بتتغير فوراً.

تجهيز بيئة العمل – Install Your Development Environment

Visual Studio Code (واسمه المختصر VS Code) هو برنامج مجاني بنكتب فيه الأكواد.

  1. افتح الموقع الرسمي: code.visualstudio.com/download
  2. اختار نسخة Windows المناسبة.
  3. دوس على التحميل وانتظر لحد ما الملف ينزل.
  4. شغّل ملف التثبيت اللي نزل.
  5. وافق على الشروط (I accept the agreement).
  6. كمّل بـNext لحد ما التثبيت يخلص.
  7. افتح Visual Studio Code.
💡 تحميل من الموقع الرسمي بسماتحملش البرامج من مواقع تانية عشان الأمان.

Extensions المهمة: Live Server

Extension إضافة بتزوّد إمكانيات VS Code. أهم واحدة لينا دلوقتي Live Server.

هي بتشغّل صفحات HTML على جهازك، وبتحدّث المتصفح لوحدها كل ما تحفظ التعديلات (Ctrl+S).

  1. افتح VS Code.
  2. دوس على أيقونة Extensions في الشريط الجانبي.
  3. اكتب في البحث: Live Server
  4. دوس Install.
  5. افتح ملف HTML.
  6. كليك يمين على الصفحة.
  7. اختار Open with Live Server.

إنشاء أول ملف HTML 📄

اسم أي ملف ليه جزئين: الاسم، وبعده الامتداد اللي بيقول نوع الملف. ملف HTML لازم ينتهي بـ .html

✅ صح

home.html
login.html
about.html

❌ غلط

index.txt

إيه حكاية index.html؟

الاسم index.html هو الاسم الشائع للصفحة الرئيسية. كتير من الاستضافات والسيرفرات بتدوّر عليه تلقائياً كصفحة افتراضية لما حد يفتح الموقع.

💡 الاسم مش إجباريينفع تعمل ملفات بأسماء تانية زي login.html وabout.html. بس خلّي الصفحة الرئيسية اسمها index.html.
⚠️ خطأ شائعلو ظهر الملف باسم index.html.txt، فويندوز مخبّي الامتداد الحقيقي. فعّل «File name extensions» من قائمة View في File Explorer.

Input Types – أنواع الخانات

الخاصية type هي اللي بتحدد نوع الـinput. اختار نوع وجرّبه:








Placeholder وValue


placeholder
نص باهت إرشادي، بيختفي أول ما تكتب.
value
قيمة حقيقية مكتوبة جوه الخانة من الأول، وتقدر تمسحها أو تعدّلها.





⚠️ لا تخلطالـplaceholder مش بيتحسب قيمة. لو الخانة فاضية والحقل محتاج بيانات، الـplaceholder ماينفعش بديل.







HTML Structure – هيكل الصفحة


<html>
<head> ← معلومات عن الصفحة (مش بتظهر)
<title> ← اسم التبويب
<body> ← اللي بيظهر للمستخدم
<h1> <p> <button> …
</html>


  • <!DOCTYPE html> بتقول للمتصفح إن الملف HTML حديث.
  • lang="ar" dir="rtl" يعني عربي واتجاهه من اليمين.
  • meta charset="UTF-8" عشان الحروف العربي تظهر صح.
  • head للإعدادات، body للمحتوى المرئي، title لاسم التبويب.
